## Usage:

You **cannot** deploy BlackWaves on static hosting services (like GitHub Pages), because it needs a server to run.

## Self-Hosting:

1. Log in to your server.
2. Open the terminal.
3. Run the commands below:

```bash
git clone https://github.com/yaanscoat/blackwaves

cd blackwaves

npm i
npm start
```

Then, open [https://localhost:8000](https://localhost:8000) and you're done!
