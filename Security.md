# Security Policy

## Supported Versions

The following versions of this project are currently supported:

| Version  | Supported          |
|----------|--------------------|
| 1.0.0    | :white_check_mark: |

## Why?

Hosting multiple versions of Blackwaves can cost a lot of money, money which I **DO NOT** have or would like to spend.

## Best Practices

- Always make sure you’re using the latest version of BlackWaves for best optimisation!

## Support

If you are having a problem with BlackWaves, open an issue on [GitHub](https://github.com/yaanscoat/blackwaves/issues) or ask in the [Discord](https://discord.gg/y2X5RtTSe).
